# TaskSmasher

## アプリケーション概要
完了したタスクをまとめて削除できる、シンプルなタスク管理アプリケーション（バックエンド）

## 製作経緯
市販の参考書とUdemyの講座でSpring Frameworkを学習して開発した、SPAのバックエンドとなるSpring Frameworkアプリケーションです。
最初にSpring Framework単体で動くアプリケーションとして作成した後、フロントエンドを開発し、このアプリケーションをバックエンドとして結合テストを行いました。
フロント、バック分離形式のアプリケーション開発を学習することを優先したため、アプリケーションの機能自体は最小限に留めました。

## 反省点と今後の課題
- 動作環境となるDockerとHerokuの学習に時間を取られたため、開発期間が想定より遅れた。
- 現時点ではiPhoneでは正常に動作しない可能性がある。セッションのCookie認証がSafariのサードパーティCookie制限に引っかかっていることが原因とみられるため、JWT認証に移行する予定。
​
## 実装した機能
- ログイン
- タスクの作成・編集・削除
- 完了・未完了の管理
- 完了済みタスク削除時のアニメーション再生
